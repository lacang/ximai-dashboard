# 西麦团队直播岗位绩效评分规则（v1）

> 用途：用户每天提供新鲜直播数据，按本规则自动计算参与评级人员的绩效分并实时展示。
> 版本：v1 · 2026-10-08

## 一、参与评级人员

- 总监组：陈山松、孙选博、韩广昊、郭士博
- 剔除：康振东、任元丰（2026-10-28 用户要求移出评级）

## 二、数据口径（如何从每日明细聚合）

输入为每日直播明细（2026.9.xlsx 为样板），字段：
`日期 / 开播时间 / 下播时间 / 直播时长h / 主播 / 副播 / 总成交额 / 广告消耗金额 / 广告成交额 / 付费ROI`

聚合规则：
- 主主播 = `主播`列中"`/`"前的名字（如 "陈山松/潘萌萌" → 陈山松）
- 按主主播聚合：直播时长求和、总成交额求和、广告消耗求和
- **ROI = 总成交额 ÷ 广告消耗金额**（验证：2026年9月1日 53236÷14911.33=3.57 ✓）
- **单小时产出 = 总成交额 ÷ 直播时长**
- 统计口径为"参与评级人员"范围内（当前5人）

**团队均值（评分基准线）必须用总量相除，不对个人比率求简单平均**（v1.1 修正，2026-10-14）：
- **平均 ROI = 全员总GMV ÷ 全员总消耗**（资金加权）
- **平均单小时产出 = 全员总GMV ÷ 全员总时长**（时长加权）
- **平均时长 = 全员总时长 ÷ 评级人数**（人均时长）
- 以上均取当期整月累计数据，自然月重置；基准随每日新增数据动态重算。

## 三、评分规则

### 1. GMV 分值（总成交额）
- 第 1 名：30 分
- 中间名次：20 分
- 最后 1 名：10 分

### 2. ROI 分值
- ROI 高于平均 ROI：30 分
- ROI 高于平均 ROI 的 90%（即 ≥ 90%平均且 ≤ 平均）：20 分
- ROI 低于平均 ROI 的 90%：10 分

### 3. 单小时成交额分值
- 第 1 名：20 分
- 中间名次：15 分
- 最后 1 名：5 分

### 4. 上播时长分值
- 时长 ≥ 平均时长：10 分
- 时长 < 平均时长：5 分
- （用户原话提到"90%"，但因两档分值相同，落地为上述两档）

## 四、总分与排名

- 总分 = GMV分 + ROI分 + 单小时产出分 + 上播时长分
- 同分时：**GMV 高者排名优先**（图片汇总表底部规则）
